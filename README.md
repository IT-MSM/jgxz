# Trust Center — GitHub Pages

موقع ثابت بالكامل لمركز **Trust Center** في المنصورة؛ لا يحتاج Node.js أو خادمًا أو قاعدة بيانات.

## الرفع إلى GitHub Pages

1. فكّ ضغط الملف وارفع محتويات المجلد إلى جذر مستودع GitHub (بما فيها `index.html` و`settings.html` ومجلد `assets`).
2. افتح **Settings → Pages** في المستودع، واختر النشر من فرع `main` ومجلد `/(root)`، ثم احفظ.
3. انتظر اكتمال GitHub Pages وافتح الرابط المنشور. الموقع يستخدم مسارات نسبية ليعمل أيضًا إذا كان منشورًا داخل مستودع GitHub Pages فرعي.

## تعديل بيانات الموقع

رابط صفحة الإعدادات مخفي من الصفحة الرئيسية. من كمبيوتر مكتبي، اكتب `0000` على لوحة المفاتيح في الصفحة الرئيسية لفتحها؛ أو افتح `/settings.html` مباشرة وأدخل الرمز. عدّل البيانات واضغط **تنزيل ملف الإعدادات**. ستنزّل الصفحة ملف `site-settings.json` على جهازك؛ انسخه إلى جذر مستودع GitHub بدل الملف القديم، ثم ارفع التغيير إلى `main` وانتظر إعادة النشر. بعد النشر يقرأ الموقع الملف الجديد ويظهر التغيير لكل الزوار.

**مهم:** GitHub Pages يستضيف ملفات ثابتة فقط. لا تستطيع صفحة الإعدادات الكتابة داخل المستودع أو تحديث الموقع المنشور تلقائيًا. هذا التدفق يدوي عن قصد، ولا يستخدم Token أو Backend. رمز `0000` إخفاء بسيط يعمل في المتصفح وليس حماية حقيقية؛ يمكن تجاوز صفحة الإعدادات أو فحص كودها. ملف `site-settings.json` عام، لذلك لا تضع بيانات سرية فيه.

## محتويات الموقع

`index.html` الصفحة الرئيسية، `settings.html` نموذج الإعدادات، `site-settings.json` البيانات التي يقرأها الموقع، `app.js` روابط التواصل والدفع، `settings.js` تنزيل ملف الإعدادات، `style.css` التنسيق المتجاوب، و`assets/` الأيقونات والشعار. `qrcode.js` يبني رمز Wi-Fi داخل المتصفح.
